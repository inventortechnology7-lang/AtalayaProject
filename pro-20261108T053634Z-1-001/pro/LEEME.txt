INVENTOR TECHNOLOGY — KATANA (servidor local Condominio Las Palmas)
Actualizado 2026-11-07. Aquí están los archivos REALES del servidor (las rutas antiguas
~/katana-servidor, ~/inventor/pantalla y ~/respaldos-katana ahora apuntan aquí).

CARPETAS
- Servidor Katana/   programas del servidor y base de datos
    katana.db        BASE DE DATOS: puertas, alarmas, logs, mediciones, pantalla, pendientes a Negra
    usuarios.db      usuarios del gestor web
    receptor.py      recibe las placas (puerto 8300)
    sync.py          envía todo a Negra (web y app)
    ui.py            gestor web http://localhost:8080 (con usuario y clave)
    test_*.py        pruebas automáticas
    .env             (oculto) contraseñas y configuración — NO compartir
- Pantalla USB/      puente entre la pantalla Arduino Minima (USB) y el servidor
- Respaldos/         copias de los archivos antes de cada cambio
- Registro/          órdenes de Negra, respuestas de Katana y avance de pruebas (copia del cerebro)

CÓMO FLUYEN LOS DATOS
Placas (R4 = Puerta A, ESP32 = Puerta B) -> Katana :8300 -> katana.db -> Negra -> web y app
                                                         -> pantalla Minima (USB)
